# Benchmark results

Committed CSV output plus figures generated from it. Every figure in the README and the
write-up must be reproducible from data in this directory — no hand-assembled numbers.

Layout, as data arrives:

- `raw/` — per-run CSVs conforming to the schema frozen by bead `t-results-schema`
- `manifests/` — one run manifest per CSV (`t-manifest`); a CSV without its manifest is
  not a result
- `figures/` — plots generated by `bench/plots.py` (`t-plots`)
- `performix/` — Arm Performix standardized reports (`t-performix`)

The master comparison table (`t-results-table`) is assembled from these files with every
cell traceable back to a manifest-backed run.
