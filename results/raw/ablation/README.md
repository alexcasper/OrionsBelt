# Ablation matrix CSVs — SYNTHETIC DATA

> ⚠️ **These CSVs contain synthetic data produced by `SyntheticBackend`, not
> real hardware measurements.** Throughput values are arbitrary analytical
> outputs. Only the memory decomposition shapes (weights / KV cache /
> recurrent state) are structurally meaningful.

## Purpose

These files validate the ablation pipeline end-to-end: the sweep grid
(`scripts/run_ablation.py`), schema conformance, manifest capture, and
comparison table generation (`results/figures/ablation_comparison.md`).
When real backends land (bead `ob-8qt.9`), the same script produces
actual numbers with an unchanged grid structure and table format.
